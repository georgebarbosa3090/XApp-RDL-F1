## 1–2. Hardware e software
| Componente | Função |
|---|---|
| **CPU** (UCP) | Processamento: **ULA** (cálculos) + **UC** (controle) + registradores |
| **RAM** | Memória principal **volátil** (perde dados sem energia) |
| **ROM / firmware (BIOS/UEFI)** | Não volátil; inicialização |
| **Cache** | Memória rápida entre CPU e RAM (L1 > L2 > L3 em velocidade) |
| HD / **SSD** | Armazenamento secundário não volátil; SSD sem partes móveis, mais rápido |
| Placa-mãe, chipset, GPU, fonte | — |

- **Hierarquia de memória** (mais rápida → mais lenta): registradores → cache → RAM → SSD → HD → mídias externas.
- **Entrada**: teclado, mouse, scanner, microfone, webcam. **Saída**: monitor, impressora, caixa de som. **Entrada e saída (híbridos)**: **touchscreen**, multifuncional, pendrive, HD externo, modem.
- **Software**: básico (**sistema operacional**), aplicativo (Word, navegador), utilitário (antivírus, compactador). **Licenças**: software livre (4 liberdades — executar, estudar, redistribuir, modificar), freeware (gratuito, código fechado), shareware (teste), proprietário.
- Unidades: 1 byte = 8 bits; 1 KB = 1.024 B; KB → MB → GB → TB → PB.
- USB: 2.0 = **480 Mbps**; 3.2 Gen 2x2 = **20 Gbps** (cobrado pela IDCAP).

## 4. Internet e navegação
- **URL**: `https://www.sead.ap.gov.br/pagina` → protocolo, domínio, caminho. **HTTPS** = HTTP + TLS (cadeado).
- **Navegação anônima/privativa**: não salva histórico, cookies e senhas **localmente**, mas **não** esconde do provedor nem do site.
- **Cookies**: pequenos arquivos que guardam preferências/sessão. **Cache**: cópia local de páginas.
- Atalhos de navegador: **Ctrl+T** nova aba, **Ctrl+Shift+T** reabrir aba fechada, **Ctrl+W** fechar aba, **Ctrl+N** nova janela, **Ctrl+Shift+N** (Chrome/Edge) ou **Ctrl+Shift+P** (Firefox) janela anônima, **Ctrl+H** histórico, **Ctrl+J** downloads, **Ctrl+D** favoritar, **Ctrl+P** imprimir, **F11** tela cheia, **Ctrl+F** localizar.

## 5. Correio eletrônico
- **Para**: destinatário principal. **Cc** (cópia): visível a todos. **Cco** (cópia oculta): os demais **não veem** quem está em Cco.
- **Responder** (só remetente) × **Responder a todos** × **Encaminhar** (mantém anexos).
- Protocolos: **SMTP** (envio, porta 25/**587**), **POP3** (recebimento, baixa e normalmente remove do servidor, 110/995), **IMAP** (recebimento sincronizado, mantém no servidor, 143/993).
- Webmail usa HTTP/HTTPS no navegador.

## 7. Excel 2019 (PT-BR)
### Referências
| Tipo | Exemplo | Ao copiar |
|---|---|---|
| Relativa | `A1` | muda linha e coluna |
| **Absoluta** | `$A$1` | não muda (F4 alterna) |
| Mista | `$A1` / `A$1` | trava só coluna / só linha |

> Ex.: `=B2*$E$1` copiada de C2 para C3 vira `=B3*$E$1`.

### Funções essenciais
| Função | Exemplo | Resultado |
|---|---|---|
| SOMA | `=SOMA(A1:A5)` | soma o intervalo (`:` = "até"; `;` = "e") |
| MÉDIA | `=MÉDIA(A1:A5)` | média aritmética (ignora células vazias e texto) |
| MÁXIMO / MÍNIMO | `=MÁXIMO(A1:A5)` | maior / menor |
| MAIOR / MENOR | `=MAIOR(A1:A5;2)` | 2º maior |
| **CONT.NÚM** | conta células com **números** | |
| **CONT.VALORES** | conta células **não vazias** | |
| CONTAR.VAZIO | conta vazias | |
| **CONT.SE** | `=CONT.SE(A1:A10;">5")` | conta com critério |
| **SOMASE** | `=SOMASE(A1:A10;"TI";B1:B10)` | soma B onde A = "TI" |
| **SE** | `=SE(A1>=7;"Aprovado";"Reprovado")` | condição |
| E / OU | `=SE(E(A1>5;B1>5);"OK";"")` | |
| **PROCV** | `=PROCV(valor;tabela;nº_coluna;FALSO)` | busca vertical (FALSO = exata) |
| ARRED | `=ARRED(2,567;2)` | 2,57 |
| HOJE / AGORA | data / data e hora | |
| CONCATENAR / & | `=A1&" "&B1` | junta textos |

> ⚠️ **PROCX** **não existe no Excel 2019** (só no 365/2021). O edital cita Excel **2019**.
> ⚠️ Toda fórmula começa com **=** (ou + / −). `=SOMA(A1;A5)` soma **só A1 e A5**; `=SOMA(A1:A5)` soma **A1 até A5**.

| Erro | Causa |
|---|---|
| `#DIV/0!` | divisão por zero |
| `#N/D` | valor não encontrado (PROCV) |
| `#NOME?` | nome de função digitado errado |
| `#REF!` | referência inválida (célula excluída) |
| `#VALOR!` | tipo de dado errado (texto em cálculo) |
| `#####` | coluna estreita demais |

- Atalhos Excel: **Ctrl+;** data atual, **Ctrl+Shift+;** hora, **F2** editar célula, **F4** alternar $, **Ctrl+1** Formatar Células, **Alt+=** AutoSoma, **Ctrl+Home** ir para A1, **Ctrl+setas** ir ao fim dos dados, **Ctrl+Shift+L** filtro.
- Gráficos: **colunas** (comparação), **linhas** (tendência no tempo), **pizza** (proporção de um todo, uma série), **dispersão** (correlação).

## 8. Aplicativos de segurança
| Ferramenta | O que faz | Não faz |
|---|---|---|
| **Antivírus** | Detecta/remove malware por **assinaturas** e **heurística/comportamento** | Não bloqueia tráfego de rede por si |
| **Firewall** | **Filtra tráfego de rede** (portas, IPs, protocolos) por regras | Não remove vírus de arquivos |
| Antispyware / antimalware | Foco em spyware, adware | — |

| Malware | Característica |
|---|---|
| **Vírus** | Precisa de **hospedeiro** e de execução para se propagar |
| **Worm** | Propaga-se **sozinho** pela rede, explora vulnerabilidades |
| **Cavalo de Troia (trojan)** | Parece legítimo, executa ações ocultas |
| **Ransomware** | **Criptografa** dados e pede **resgate** |
| **Spyware** / **Keylogger** / Screenlogger | Espiona; captura **teclas** / tela |
| **Backdoor** | Porta dos fundos para acesso remoto |
| **Rootkit** | Esconde a presença do invasor, acesso privilegiado |
| **Bot / Botnet** | Máquina zumbi controlada remotamente (DDoS) |
| Adware | Propaganda indesejada |

- Golpes: **phishing** (mensagem falsa para roubar dados), **pharming** (redireciona DNS para site falso), **spoofing** (falsifica remetente), **engenharia social**.

## Questões comentadas (estilo IDCAP)

**Q1.** No Microsoft Word 2019 em português, os atalhos para **negrito** e **salvar** são, respectivamente:
(A) Ctrl+B e Ctrl+S. (B) **Ctrl+N e Ctrl+B.** (C) Ctrl+N e Ctrl+S. (D) Ctrl+G e Ctrl+B.
✅ **B.** Em PT-BR: Ctrl+N = Negrito, Ctrl+B = Salvar, Ctrl+S = Sublinhado. A alternativa A traz os atalhos da versão em inglês.

**Q2.** No Excel 2019, a célula C1 contém `=A1*$B$1`. Copiando C1 para C3, obtém-se:
(A) `=A1*$B$1`. (B) **`=A3*$B$1`.** (C) `=A3*$B$3`. (D) `=C3*$B$1`.
✅ **B.** A1 é relativa (desce duas linhas), $B$1 é absoluta.

**Q3.** O destinatário incluído no campo Cco de uma mensagem:
(A) recebe a mensagem sem anexos. (B) **recebe a mensagem, mas os demais destinatários não sabem que ele a recebeu.** (C) só recebe se o remetente autorizar. (D) aparece para todos como cópia.
✅ **B.**

**Q4.** Malware que se replica automaticamente pela rede, explorando vulnerabilidades, sem necessidade de um arquivo hospedeiro:
(A) vírus. (B) **worm.** (C) trojan. (D) adware.
✅ **B.**
