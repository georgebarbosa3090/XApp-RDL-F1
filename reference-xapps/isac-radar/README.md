# ISAC Radar (experimental)

Gerador de propostas de divisão de recursos entre comunicação e sensoriamento, escrito para este projeto.

- **Parâmetro:** `SENSING_RATIO` (0–0,60, padrão 0,35).
- **Limitação:** não há codificação RC nem efeito na simulação ns-3 para este parâmetro.
- **Métricas:** `/metrics` com `isac_radar_proposals_total`, `isac_radar_sensing_ratio`.
