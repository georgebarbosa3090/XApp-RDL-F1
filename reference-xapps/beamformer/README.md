# Beamformer (experimental)

Gerador de propostas de inclinação elétrica, escrito para este projeto.

- **Parâmetro:** `VERTICAL_DOWNTILT` (0–15°, padrão 6°).
- **Limitação:** não há codificação RC nem efeito na simulação ns-3 para este parâmetro.
- **Métricas:** `/metrics` com `beamformer_proposals_total`, `beamformer_downtilt_degrees`.
